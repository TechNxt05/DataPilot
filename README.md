### 🧠 1. Neural Execution DAG
Visualize the AI's "thought graph" in real-time. Powered by **React Flow**, the DAG shows branching analyses, retries, and healed nodes as the mission progresses.

### 🪄 2. Autonomous Discovery Mode
One-click "Magic Wand" discovery. The system performs a deep-dive audit—detecting anomalies, generating hypotheses, and benchmarking forecasts—without any human input.

### 📜 3. Thought Stream (Reasoning Visibility)
A high-fidelity log of actual orchestration events. Watch the agents debate, reflect, and repair logic in a terminal-style stream of consciousness.

### 💡 4. Strategic Hypothesis Console
The AI doesn't just show charts; it proposes theories. Each hypothesis includes:
- **Confidence Scores**
- **Supporting Evidence**
- **Conflicting Indicators**
- **Recommended Actions**

### 🚑 5. Self-Healing Analytics
When execution hits a bottleneck or an error, the Reflection Agent inspects the stack trace, rewrites the code, and restarts the node, exposing the "repair logic" to the user.

## 🚦 Deployment & Initialization

### Docker Mission Launch (Recommended)
The fastest way to deploy the full "Neural Horizon" stack:
```bash
docker-compose up --build
```

### Manual Neural Link (Local Development)

**1. Synchronize Backend**:
```bash
pip install -r requirements.txt
uvicorn api.main:app --reload --port 8000
```

**2. Initialize Mission Control**:
```bash
cd frontend
npm install
npm run dev
```

Visit `http://localhost:3000` to launch the platform.
